Alice Co-op — экспериментальный кооперативный мод на двух игроков для Windows-версии
*Alice: Madness Returns*. Каждый игрок запускает собственный процесс игры, а
небольшой UDP-сервер передаёт положение игроков, анимации и состояние мира. Для
обычных противников состояние хоста считается основным.

> [!WARNING]
> Это альфа-версия для плейтестов. Сделайте резервную копию сохранений,
> используйте отдельный кооперативный профиль и будьте готовы иногда перезапускать
> чекпоинт в сложных скриптовых сценах.

## Игровой процесс

![Игровой процесс Alice Co-op из текущей альфа-версии](docs/media/alice-co-op-gameplay-preview.webp)

*Настоящий игровой процесс текущей альфа-версии. Баннер — неофициальный
промоматериал с элементами, созданными при помощи ИИ.*

## Что уже работает

- Хост и клиент видят друг друга и независимо управляют своими Алисами.
- Передаются ходьба, прыжки, полёт, уменьшение, рывок, часть атак, выбранное
  оружие, волосы, платье и основные визуальные эффекты прокси.
- Позиция, здоровье и смерть обычных мобов синхронизируются от хоста.
- Враги способны менять цель между хостом и клиентом и наносить урон обоим.
- Многие ящики и другие разрушаемые объекты ломаются у обоих; лут остаётся
  индивидуальным.
- Смерть, продолжение с чекпоинта и выход в главное меню координируются.
- Многие катсцены от взаимодействий и триггеров запускаются синхронно.
- Клиент может присоединиться к чекпоинту хоста и вручную скопировать его профиль
  после отдельного предупреждения и проверки целостности файлов.
- Телепорты и принудительный запуск катсцены помогают выйти из рассинхрона.

Это не настоящий встроенный мультиплеер Unreal Engine 3. Оба процесса по-прежнему
локально симулируют часть уровня, а мод согласовывает те состояния, которые можно
безопасно обнаружить во время работы игры.

## Требования

- Лицензионная PC-версия *Alice: Madness Returns* из Steam или EA App.
- Windows 10/11 x64; сама игра и мод 32-битные.
- Microsoft Visual C++ Redistributable 2015–2022 **x86**.
- Одинаковая версия Alice Co-op на обоих компьютерах.
- Localhost, доверенная локальная сеть или VPN, например Radmin VPN.

В Alice Co-op уже включена объединённая DLL на основе
[MadnessPatch 3.1.1](https://github.com/Wemino/MadnessPatch/releases/tag/3.1.1).
Отдельно устанавливать MadnessPatch не требуется.

## Быстрый запуск

Если удобнее посмотреть видео, откройте
[инструкцию по установке и настройке на YouTube](https://www.youtube.com/watch?v=UzjCvp7MhTM).

1. Закройте игру на обоих компьютерах.
2. Скачайте `AliceCoop-*-drop-in.zip` на странице
   [Releases](https://github.com/docwitson/Alice-Madness-Returns-Co-op/releases).
3. Распакуйте содержимое архива в папку с `AliceMadnessReturns.exe`:

   ```text
   <папка игры>\Binaries\Win32
   ```

4. Запустите ровно один relay-сервер на любом из двух компьютеров:

   ```text
   AliceCoop\AliceCoop-Server.bat
   ```

5. **Steam:** на обоих компьютерах откройте `AliceCoop\AliceCoop.ini`. Укажите
   `EnableWithoutLauncher = 1`, `Role = host` у хоста и `Role = client` у
   клиента. В `ServerAddress` впишите IP компьютера с relay-сервером;
   `127.0.0.1` используйте только на том же самом ПК. У обоих игроков должен
   совпадать `Port`.
6. Запустите обе игры обычным способом через Steam. В оверлее должна появиться
   настроенная роль `HOST` или `CLIENT`.
7. **EA App или запуск через BAT:** оставьте `EnableWithoutLauncher = 0`,
   настройте `SERVER_IP` и `COOP_PORT` в `AliceCoop-LaunchConfig.bat`, затем на
   каждом компьютере используйте соответствующий скрипт:

   ```text
   AliceCoop\AliceCoop-Host.bat
   AliceCoop\AliceCoop-Client.bat
   ```

8. Загрузите совместимые профили. В главном меню клиент может выбрать
   `SYNC HOST SAVE`, чтобы скопировать прогресс хоста. Внимательно прочитайте
   предупреждение: выбранный клиентский профиль будет перезаписан.
9. После загрузки уровня, если клиент оказался далеко от хоста, нажмите `O`.

Сервер может работать на компьютере любого игрока. Разрешите входящий UDP для
выбранного порта, по умолчанию `27018`. Не открывайте сервер напрямую в Интернет:
в прототипе нет аутентификации и шифрования.

Подробности находятся в [инструкции по установке](docs/INSTALL_RU.md).

## Управление модом

| Клавиша | Где работает | Действие |
| --- | --- | --- |
| `P` | Геймплей | Безопасный телепорт: клиент к хосту, хост к клиенту |
| `O` | Геймплей клиента | Принудительный телепорт к хосту без проверки расстояния |
| `L` | Видна жёлтая кнопка | Подключиться к чекпоинту или принудительно запустить ожидающую катсцену |
| `K` | Главное меню клиента | Открыть предупреждение о синхронизации профиля |
| `T` | Меню паузы | Переключить ограниченную историю следов движения прокси |

В остальных ситуациях клавиши остаются в распоряжении самой игры.

## Настройка

Параметры запуска через BAT находятся в:

```text
AliceCoop\AliceCoop-LaunchConfig.bat
```

Сетевые, прокси- и диагностические параметры находятся в:

```text
AliceCoop\AliceCoop.ini
```

Настройки MadnessPatch находятся в `MadnessPatch.ini` рядом с exe игры. Смотрите
[описание конфигурации (англ.)](docs/CONFIGURATION.md).

## Основные ограничения

- Боссы и сложные волны мобов иногда расходятся между процессами.
- Некоторые рычаги, пятачки свиней, платформы и секреты остаются локальными.
- Анимации верхней части тела, прицеливание, волосы, жёсткое платье и частицы
  прокси являются приближением и могут отличаться от окна владельца.
- Прокси шляпы-бомбы не воспроизводит все детали оригинала.
- Ожидание катсцен основано на эвристиках. Принудительный запуск используйте
  только если оба игрока действительно застряли.
- Уровни с кораблём и видом сбоку специально проходят параллельно в соло-режиме.
- Синхронизация профиля перезаписывает выбранный профиль клиента.

Полный список и способы восстановления находятся в документе
[Known issues and recovery (англ.)](docs/KNOWN_ISSUES.md).

## Сборка из исходников

Откройте `AliceCoop.sln` в Visual Studio 2022 и соберите `Release|x86` либо
выполните:

```powershell
& .\tools\Build-AliceCoop-Package.ps1
```

Нужны workload C++ и Windows 10/11 SDK. Результаты компиляции и архивы релиза
исключены из Git. Подробности находятся в
[инструкции для разработчиков (англ.)](docs/DEVELOPMENT.md).
