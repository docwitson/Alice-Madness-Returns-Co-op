# Security policy

## Supported versions

Only the latest published Alice Co-op release is supported.

## Network warning

Alice Co-op's UDP relay is designed for localhost, a trusted LAN, or a trusted VPN
such as Radmin VPN. It has no authentication, encryption, identity verification,
or protection against hostile packets. Do not port-forward it to the public
Internet and do not run the server on an untrusted network.

## Reporting a vulnerability

Do not publish exploitable network or file-handling vulnerabilities in a public
issue. Use GitHub's private vulnerability reporting feature when it is enabled,
or contact the repository owner through their GitHub profile.

Do not attach player saves, crash dumps, logs containing personal paths, IP
addresses, or access tokens to a public report without reviewing and redacting
them first.
