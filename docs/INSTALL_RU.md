# Установка и обновление

## Выбор архива

- `AliceCoop-<версия>-drop-in.zip` — распаковывается непосредственно в
  `Binaries\Win32`.
- `AliceCoop-<версия>-installer.zip` — распаковывается в любое место, после чего
  запускается `Install-AliceCoop.bat`. Установщик находит игру, сохраняет
  существующий `MadnessPatch.ini` и создаёт резервную копию старой `dinput8.dll`.

В обоих архивах находятся одинаковые DLL клиента и сервер.

## Папка игры

Нужна папка с `AliceMadnessReturns.exe`, обычно:

```text
Steam:  <SteamLibrary>\steamapps\common\Alice Madness Returns\Binaries\Win32
EA App: <папка EA>\Alice Madness Returns\Game\Alice2\Binaries\Win32
```

Не распаковывайте мод просто в корневую папку `Alice Madness Returns`.

## Чистая установка

1. Закройте все процессы игры.
2. Сделайте копию сохранений и существующих `dinput8.dll`/`MadnessPatch.ini`.
3. Распакуйте drop-in архив в `Binaries\Win32` с сохранением структуры каталогов.
4. Проверьте наличие файлов:

   ```text
   AliceMadnessReturns.exe
   dinput8.dll
   MadnessPatch.ini
   AliceCoop\AliceCoopServer.exe
   AliceCoop\AliceCoop.ini
   AliceCoop\AliceCoop-LaunchConfig.bat
   ```

5. Если игра закрывается до появления окна, установите Microsoft Visual C++
   Redistributable 2015–2022 x86.

`dinput8.dll` уже содержит MadnessPatch 3.1.1. Установить рядом вторую DLL с тем
же именем невозможно: одна версия заменит другую.

## Обновление

У обоих игроков должны совпадать версия Alice Co-op и версия протокола.

1. Закройте игру и сервер.
2. Сохраните настроенный `AliceCoop\AliceCoop-LaunchConfig.bat`, а также изменённые
   `AliceCoop.ini` и `MadnessPatch.ini`.
3. Замените DLL, сервер, скрипты, изображения и документацию файлами нового релиза.
4. Проверьте changelog на наличие новых параметров.

Installer-архив создаёт резервные копии автоматически. При ручной распаковке
drop-in архива сохранность изменённых конфигов зависит от выбранного архиватора.

## Сеть

- Для двух игроков запускается ровно один `AliceCoopServer.exe`.
- Сервер может работать на ПК хоста, клиента или другом доверенном Windows-ПК.
- Для запуска через Steam укажите `EnableWithoutLauncher = 1` и нужную роль
  `Role = host` или `Role = client` в каждом `AliceCoop.ini`. В `ServerAddress`
  впишите адрес ПК с relay-сервером, укажите одинаковый `Port` и запускайте игру
  обычным способом через Steam.
- Для запуска через BAT у обоих игроков должны совпадать `SERVER_IP` и
  `COOP_PORT` в `AliceCoop-LaunchConfig.bat`.
- По умолчанию сервер слушает `0.0.0.0`, поэтому принимает localhost, LAN и VPN.
- Разрешите входящий UDP на порту `27018` или выбранном вами порту.
- Не пробрасывайте этот порт напрямую в Интернет.

## Профили

Для клиента лучше создать отдельный кооперативный профиль. Можно пройти пролог
обычным способом либо использовать `SYNC HOST SAVE` (`K`) в главном меню.
Синхронизация:

- показывает предупреждение о перезаписи;
- передаёт выбранные файлы прогресса хоста подтверждаемыми частями;
- проверяет SHA-256 до применения;
- сохраняет предыдущие клиентские файлы с суффиксом `.alicecoop-presync.bak`;
- после успеха требует перезапустить только клиент.

Не закрывайте игры и сервер во время передачи.

## Удаление

Запустите `AliceCoop\Uninstall-AliceCoop.bat`. Если установщик сохранил старую
`dinput8.dll`, он предложит восстановить её. Файлы оригинальной игры не удаляются.
