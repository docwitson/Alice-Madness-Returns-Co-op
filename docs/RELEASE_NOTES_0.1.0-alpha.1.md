# Alice Co-op 0.1.0-alpha.1

This is the first alpha release of Alice Co-op, an experimental
two-player cooperative mod for *Alice: Madness Returns*.

The release includes:

- the combined Alice Co-op + MadnessPatch 3.1.1 `dinput8.dll`;
- the standalone UDP relay server;
- host/client/local-test launch scripts;
- English and Russian installation documentation;
- installer and direct drop-in archives with SHA-256 checksums.

Before playing, both users must install this exact release. Back up saves and use
a dedicated client co-op profile. The relay is intended for localhost, trusted
LAN, or trusted VPN use only.

This alpha has known limitations in bosses, heavily scripted encounters, remote
animations and some locally simulated world mechanisms. See `KNOWN_ISSUES.md` in
the archive or repository before reporting a problem.
